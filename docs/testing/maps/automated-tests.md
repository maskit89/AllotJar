CI (`.github/workflows/ci.yml`): jobs `backend` (dotnet test AllotJar.slnx, EF **InMemory** — FK-blind, no SQL), `integration` (mssql 2022 service container; also runs the journey steps on main and hand-started runs; targets `tests/AllotJar.IntegrationTests/*.csproj` directly — the project is deliberately OUTSIDE `AllotJar.slnx`), journey steps inside the `integration` job (same mssql container + live API :5099 + Vite :4173, `npm run test:e2e:journey`; **not a required check**), `frontend` (`npm run test` = vitest, then `npm run build` = tsc + vite build), `a11y` (`npm run test:e2e` = stubbed Playwright axe scans; not required: the main ruleset requires only `backend` and `frontend`), `security-scan` (now its own weekly workflow, `security-scan.yml`, Thursdays 07:30 UTC plus hand-started: NuGet vulnerable-package grep + `npm audit --audit-level=high`; not required). Docs-only pushes to main skip CI, and a docs-only PR skips the heavy jobs via the `changes` job (required checks still report); production's `ci-passed` check looks back to the last code commit's CI run. `npm run lint` is red app-wide and **not gated** — do not treat lint as a coverage signal.

## Layer inventory (file lists, what each layer asserts, gaps)

### Layer 1 — Client unit tests (Vitest + React Testing Library, jsdom)

Runner: `npm run test` (`vitest run`); config lives in `client/vite.config.ts` (`test.include: 'src/**/*.test.{ts,tsx}'`, `environment: 'jsdom'`, `setupFiles: './src/test/setup.ts'`, `css: false`). Setup file (`client/src/test/setup.ts`) registers jest-dom matchers, installs an in-memory `localStorage` polyfill, and a same-process **`BroadcastChannel` polyfill** (delivered to every OTHER instance via microtask) — this is what makes the PR #169 cross-tab sign-out tests possible. Cleanup + `localStorage.clear()` after each test.

Standard harness pattern (e.g. `client/src/pages/TransactionsPage.test.tsx:7-21`): `vi.hoisted` mock fns + `vi.mock('../lib/api', async (importOriginal) => ({ ...(await importOriginal()), api: { get, put, post, delete }, getToken, setToken }))` — **the spread of `importOriginal` is load-bearing** (PR #169 gotcha: new api.ts exports must keep working under test). Pages render inside `<MemoryRouter><AuthProvider>…`.

## 6. Computed/derived values & money rules (as tested)

- Client: integer minor units at scale 4; `remaining(item) = plannedMinor − actualMinor`; pool `remainingToBudget = totalIncome − plannedTotal` where income lines are EXCLUDED from plannedTotal and Savings/fund contributions are INCLUDED; `isBalanced = remaining == 0 AND totalIncome > 0` (budgetModel.test:114, PR #172). Signed amount by direction. Locale formats: de-DE, en-GB (default), fr-FR, de-CH, en-IN; symbol independent of grouping.
- Server: `RemainingToBudget` mirrors the client formula at decimal(18,4) precision (4-decimal test); `IsBalanced_RequiresIncome_NotJustZeroRemaining`; Money forbids cross-currency arithmetic; there is no exchange rate (W08): a row in another currency waits (`FxPending`) and counts nowhere until its budget-currency amount is confirmed, and a suggestion is `round(amount × ECB rate, 2)`; account balance = opening + assigned tx (derived at read, never stored); jar balance = opening + contributions − spend, counted only through the viewed month; actuals sum only assigned expense transactions for the owner, at their budget-currency amounts, leaving waiting rows out; the ForeignAmounts migration keeps a previously converted row counting at the same figure.
- Jar schedules (W02/W03/W04): TargetByDate splits the remainder in whole cents over the eligible months to the one before the deadline, remainder last, whole remainder when due now or passed, 0 when funded; a skipped month (`JarPlanOptions.SkippedMonths`) plans 0 and the rest spreads over the others, with `Unplanned` reported when none is left; FixedMonthly caps the final month and estimates; an archived or completed jar plans nothing; a Recurring jar plans toward its persisted open cycle, the next cycle is stepped from the anchor preserving month-end days, and a missed cycle never rolls on its own.
- Allocation: waterfall reproduces the Bank Summary 2026 spreadsheet; Equally + ByIncome splits sum exactly (odd cents included); BalanceTilt bounded for all lean settings (no overflow), full lean → everything to the lower balance; transfers idempotent on rerun (same references, unique index quiet).
- Import money: success tiles are real sums (journey asserts `2,500.00` in / `46.30` out from 42.50+3.80).
