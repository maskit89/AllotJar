## Layer inventory (file lists, what each layer asserts, gaps)

### Layer 1 — Client unit tests (Vitest + React Testing Library, jsdom)

Runner: `npm run test` (`vitest run`); config lives in `client/vite.config.ts` (`test.include: 'src/**/*.test.{ts,tsx}'`, `environment: 'jsdom'`, `setupFiles: './src/test/setup.ts'`, `css: false`). Setup file (`client/src/test/setup.ts`) registers jest-dom matchers, installs an in-memory `localStorage` polyfill, and a same-process **`BroadcastChannel` polyfill** (delivered to every OTHER instance via microtask) — this is what makes the PR #169 cross-tab sign-out tests possible. Cleanup + `localStorage.clear()` after each test.

Pages render inside `<MemoryRouter><AuthProvider>…`.

## 6. Computed/derived values & money rules (as tested)

- Client: integer minor units at scale 4; `remaining(item) = plannedMinor − actualMinor`; pool `remainingToBudget = totalIncome − plannedTotal` where income lines are EXCLUDED from plannedTotal and Savings/fund contributions are INCLUDED; `isBalanced = remaining == 0 AND totalIncome > 0` (budgetModel.test:114, PR #172). Signed amount by direction. Locale formats: de-DE, en-GB (default), fr-FR, de-CH, en-IN; symbol independent of grouping.
- Server: `RemainingToBudget` mirrors the client formula at decimal(18,4) precision (4-decimal test); `IsBalanced_RequiresIncome_NotJustZeroRemaining`; Money forbids cross-currency arithmetic; `Transaction.BaseAmount = amount × exchangeRate`; account balance = opening + assigned tx (derived at read, never stored); jar balance = opening + contributions − spend, counted only through the viewed month; actuals sum only assigned expense transactions for the owner, FX-adjusted.
- Jar schedules (W02/W03/W04): TargetByDate splits the remainder in whole cents over the eligible months to the one before the deadline, remainder last, whole remainder when due now or passed, 0 when funded; a skipped month (`JarPlanOptions.SkippedMonths`) plans 0 and the rest spreads over the others, with `Unplanned` reported when none is left; FixedMonthly caps the final month and estimates; an archived or completed jar plans nothing; a Recurring jar plans toward its persisted open cycle, the next cycle is stepped from the anchor preserving month-end days, and a missed cycle never rolls on its own.
- Allocation: waterfall reproduces the Bank Summary 2026 spreadsheet; Equally + ByIncome splits sum exactly (odd cents included); BalanceTilt bounded for all lean settings (no overflow), full lean → everything to the lower balance; transfers idempotent on rerun (same references, unique index quiet).
- Import money: success tiles are real sums (journey asserts `2,500.00` in / `46.30` out from 42.50+3.80).
